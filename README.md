# Employee Attrition Prediction (Dissertation)

This project focuses on predicting employee attrition using machine learning. It was completed as part of my MSc Artificial Intelligence dissertation at Sheffield Hallam University.

---

## 📌 Objectives

- Analyze employee data to identify key attrition drivers
- Apply machine learning models to predict whether an employee is likely to leave
- Evaluate models for interpretability and performance

---

## 🛠️ Tools & Libraries

- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- XGBoost, LightGBM
- Jupyter Notebook

---

## 🧠 Model Pipeline

- Data preprocessing: encoding, normalization, missing values
- Exploratory Data Analysis (EDA): attrition trends by department, job role, satisfaction
- Models: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting
- Evaluation: Accuracy, Precision, Recall, F1 Score, Confusion Matrix

---

## 📈 Results

- **Best Model**: Gradient Boosting
- **Accuracy**: ~85%
- High precision and recall on minority class (employees who left)
